## FAQ

### What exactly is XCutors?

XCutors is a curated collection and launcher package for several popular Windows-based Roblox script execution tools. It is not a single executor, but a suite designed to make managing multiple ones easier.

### Is it safe to use?

This repository provides official, clean copies of public executor tools. As with any third-party software interacting with games, use it at your own discretion and understand the potential risks, including account actions from the game developer.

### How do I update the executors?

Check the XCutors GitHub repository periodically for new releases. Download and replace your existing folder with the updated package to get the latest versions of the bundled executors.

### Which executor should I choose?

Each executor has its own features and interface. Volt, Synapse Z, Potassium, and Wave are all popular options. We recommend trying each one through the launcher to see which you prefer for your scripts.

### Does this work on macOS or Linux?

No, XCutors and the executors it contains are designed and built exclusively for the Windows operating system.

### My anticomponent is flagging a file. Is that normal?

Some security software may flag executor files due to their nature of modifying game processes. This is a common false positive. You may need to add an exception for the folder, but always scan files and only run software you trust.

### Do I need to install each executor separately?

No, the entire suite, including all executors and the universal launcher, is contained within the single extracted folder. Just run the main launcher to access them all.

### Where can I get scripts to run?

You can find Lua scripts for Roblox on various community forums, Discord servers, and websites dedicated to Roblox scripting. Remember to use scripts responsibly and within the game's terms of service.
